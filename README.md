# Student Performance Analytics System

## 1. Project Overview
The Student Performance Analytics System is a Python-based data analysis project. It analyzes student marks and attendance and generates a performance report.

## 2. Objective
- Calculate total and average marks.
- Assign grades to students.
- Identify pass and fail students.
- Calculate class performance.
- Analyze subject-wise averages.
- Identify top-performing students.
- Analyze student attendance.

## 3. Technologies Used
- Python
- NumPy
- Pandas
- Visual Studio Code

## 4. Project Files
- `main.py` - Main program that runs the analysis.
- `functions.py` - Contains reusable calculation functions.
- `students.csv` - Contains 20 student records.
- `README.md` - Project description and instructions.

## 5. Features
- Student dataset loading using Pandas.
- Total and average marks calculation.
- Grade and pass/fail classification.
- Highest, lowest, and class average calculation.
- Subject-wise performance analysis.
- Top-performing student identification.
- Attendance analysis.

## 6. How to Run
1. Install Python.
2. Install the required libraries:

   `python -m pip install numpy pandas`

3. Open the project folder in VS Code.
4. Run the program:

   `python main.py`

## 7. Passing Rule
A student passes if they score at least 40 marks in every subject.

## 8. Grade Rules
- A+: 90 and above
- A: 80 to below 90
- B: 70 to below 80
- C: 60 to below 70
- D: 50 to below 60
- F: Below 50

## 9. Dataset
The CSV file contains 20 student records with student ID, name, department, subject marks, and attendance.

## 10. Conclusion
This project demonstrates how Python, NumPy, and Pandas can be used to process student data and generate useful academic performance statistics.
